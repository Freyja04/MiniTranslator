MiniTranslator Native Third-Party Notices
==========================================

The native MiniTranslator executable is built with the Microsoft Visual C++
toolchain and Windows SDK. It uses Win32, Windows Runtime, Windows OCR, and
C++/WinRT system interfaces. No Qt, Python, .NET, Tauri, NuGet package, OCR
model, or third-party runtime DLL is bundled in the default native release.

Network service notice
----------------------

The key-free translation providers communicate with public web pages or
first-party client endpoints. They are not official developer APIs. They can be
rate-limited, changed, or disabled without notice, and their use may be subject
to each provider's terms of service. User-defined large-model endpoints send the
recognized text to whatever server the user configures, under that server's
terms.
